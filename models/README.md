# Trained model objects

Workflow 02 generates the fitted objects listed below:

- `dssat_ew_rf_yield.rds`
- `dssat_ew_rf_n2o.rds`
- `dssat_ew_rf_ch4.rds`
- `model_manifest.csv`

The `.rds` files contain the trained Random Forest, predictor list,
smooth-truncation parameter, hyperparameters, software versions, and training
data fingerprint. The model objects and `model_manifest.csv` form the
publication release artifacts for the DOI-bearing archive.
